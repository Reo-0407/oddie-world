# 오디 월드 2D — 처음부터 다시 (2026-11-11)

3D 오픈월드는 걷는 것 말고 할 일이 없고 건물·지형이 보기 싫어서 버린다(태그 `legacy-3d-v1`에 남김).
오디(데이터 165종, 배틀 엔진, 썸네일 `public/thumbs/OD-###.png`), 계정·클라우드 저장, 친구 대전, 도감은 그대로 쓴다.

## 게임 한 줄

옛날 포켓몬처럼 **위에서 내려다보는 2D 타일 모험**. 마을에서 출발해 네 구역(초원·사막·설원·화산)의 **체육관 우두머리 4명**을 차례로 이기고 마지막 **챔피언**에게 도전한다. 풀숲에서 야생 오디를 만나 싸우고, 이기면 로프로 잡아 도감을 채운다.

## 보이는 것

- Canvas 2D, 타일 32px, 화면은 가로 15×세로 11타일 정도(폰 세로면 9×13). 카메라가 플레이어를 따라간다. 정수 배율로 또렷하게.
- 타일 그림은 코드로 그린다(이미지 파일 없음): 풀, 풀숲(진한 풀+풀잎), 길(모래색), 물(물결 2프레임), 나무(둥근 잎+기둥), 꽃, 울타리, 바위, 모래, 눈, 얼음, 용암, 화산암, 집 벽, 지붕(색 여러 개, 기와 줄), 문, 간판, 창문, 체육관 바닥, 카펫, 카운터. 건물은 여러 타일로 이루어진 그림이라 예뻐 보여야 한다(지붕 3줄: 꼭대기 밝은 줄, 기와, 처마 그림자).
- 플레이어는 코드로 그린 작은 사람(머리·몸·다리, 4방향, 걷기 2프레임). 캐릭터 색은 6가지 중 선택.
- 오디는 썸네일 PNG를 48px로 줄여 필드(우두머리 NPC 옆, 체육관 장식)와 전투에 쓴다. 전투에서 상대는 오른쪽 위에 크게(160px), 내 오디는 왼쪽 아래 뒷모습 대신 좌우 반전 썸네일(128px).
- 전투 화면도 DOM/CSS: 배경은 구역색 그라데이션+바닥 타원, 체력판, 메시지 상자(한 글자씩 출력), 기술 버튼 4개(타입색), 가방·교체·도망. 피해 숫자가 떠오르고, 맞은 쪽이 흔들리고 깜빡인다.

## 조작

- 키보드: 방향키/WASD 이동, Z/Enter/Space 확인·말걸기, X/Esc 취소·메뉴.
- 폰: 왼쪽 아래 십자키(4버튼), 오른쪽 아래 A(확인)·B(메뉴) 버튼. 모두 터치 전용 `touch-action: none`.
- 이동은 칸 단위. 한 칸 이동에 0.18초, 부드럽게 보간. 벽·물·나무·NPC는 못 지나간다.

## 세계

하나의 큰 바깥 지도(타일 100×100)와 건물 안 지도들. 문 타일을 밟으면 안으로 들어가고, 안에서 입구 카펫을 밟으면 나온다.

바깥 지도(위가 북쪽):
- **북서 초원**: 시작 마을 「오디 마을」(오디 센터=회복, 상점, 집 2채, 연구소, 초원 체육관), 1번 길(풀숲, 트레이너 2), 숲.
- **북동 사막**: 사막 마을(센터, 상점, 사막 체육관), 2번 길(선인장, 바위, 트레이너 3).
- **남서 설원**: 설원 마을(센터, 상점, 설원 체육관), 3번 길(얼음·눈 풀숲, 트레이너 3).
- **남동 화산**: 화산 마을(센터, 상점, 화산 체육관), 4번 길(화산암, 용암 웅덩이, 트레이너 3), 가장 남동쪽에 **챔피언의 전당**.
- 구역 사이에는 **문지기 NPC**가 길을 막고 있다. 초원→사막은 초원 배지, 사막→설원은 사막 배지, 설원→화산은 설원 배지, 전당은 배지 4개가 필요하다. 배지 없으면 "OO 체육관 배지를 받아 와" 하고 못 지나간다.

야생 오디: 풀숲 타일에서 한 걸음마다 12%. 종은 구역 가중치(`regions.ts`의 typeWeights 재사용, 모델 유무와 상관없이 165종 전부 후보지만 썸네일 없는 종은 색 카드). 레벨: 초원 3~6, 사막 10~14, 설원 17~22, 화산 25~30.

트레이너 NPC: 바라보는 방향으로 최대 4칸 시야. 플레이어가 들어오면 "!" 말풍선 뒤 걸어와 전투. 팀 1~3마리. 이긴 트레이너는 저장(`beaten`)되어 다시 안 싸운다. 체육관 우두머리는 체육관 안쪽 끝에 있고 팀 3마리(구역 타입, 레벨은 길 야생보다 +3), 이기면 배지 + 코인 큰 보상. 챔피언은 팀 5마리 레벨 32~35, 이기면 엔딩 문구(크레딧: 「Catch an Oddie」 캐릭터).

전투 규칙(엔진 그대로): 야생은 **이기면** 쓰러진 오디에게 로프를 던질 수 있다(상대 체력 0 상태로 포획률 계산, 등급별). 도망은 야생만. 트레이너전은 포획 없음. 지면 마지막 오디 센터로 돌아가고 팀 회복, 코인 절반 잃음.

오디 센터: 말 걸면 팀 전부 회복, 「부활 지점」이 여기로. 상점: 로프·튼튼한 로프·회복약(기존 shop.ts). 연구소: 첫 방문 때 스타터 3마리 중 선택(기존 StarterScreen 재사용) + 로프 5개.

도감: 기존 DexOverlay. B 메뉴에서 열기. 5종마다 보상(기존 `dexMilestoneReward`).

## 저장(v5)

`SaveData`: version 5, name, characterIndex, team, box, ropes, coins, potions, dex, **map**(지도 id), **x, y, facing**, **badges**(string[]), **beaten**(string[] 트레이너 id), **flags**(string[] 예: 'starter', 'intro'), **respawn**({map,x,y}). v4 이하는 마을 시작점으로 옮기고 badges/beaten/flags 빈 배열. 클라우드 저장 JSON은 그대로 saves 표에 들어간다(200KB 이하).

## 전투를 포켓몬 고처럼 (2026-11-11 추가, 위 "전투 화면" 설명을 대신한다)

오프라인 전투(야생, 트레이너, 체육관, 챔피언)는 **실시간**이다. 친구 대전(온라인)은 공정성 때문에 지금의 턴제 서버 그대로 둔다.

- **화면**: 상대 오디가 화면 가운데 위쪽에 크게(썸네일 220px, 숨 쉬듯 위아래로 움직임), 내 오디는 왼쪽 아래에 작게 뒤에서 보는 느낌(좌우 반전 140px). 배경은 구역별 하늘 그라데이션 + 바닥 원판 그림자. 위에 양쪽 체력바(이름, Lv, CP처럼 보이는 전투력 숫자), 아래에 에너지 막대와 필살기 버튼.
- **기본 공격**: 화면 아무 곳이나 탭하면 기본 공격(0.6초 쿨타임). 맞을 때마다 피해 숫자, 반짝임, 상대 흔들림. 기본 공격은 에너지를 채운다.
- **필살기**: 내 오디의 기술 중 위력이 큰 것 최대 2개가 필살기. 에너지가 차면 버튼이 빛나고, 누르면 큰 연출(화면 번쩍, 타입색 원형 파동) 후 큰 피해. 효과(능력 변화, 상태이상)는 기존 기술 효과를 쓴다.
- **상대 공격**: 상대도 일정 간격(속도 능력치로 1.0~2.0초)으로 기본 공격, 가끔 필살기 예고("!" 빨간 테두리 1초) 후 큰 공격.
- **피하기**: 왼쪽/오른쪽으로 쓸어 넘기면(키보드 ←/→) 0.5초 동안 피하기. 필살기 예고 중에 피하면 피해 75% 감소.
- **교체/도망**: 위쪽 작은 버튼. 교체는 3초 쿨타임. 도망은 야생만.
- **피해 계산**: 기존 엔진의 `damage.ts`(타입 상성, 자속, 급소) 재사용. 기본 공격은 내 기술 중 가장 약한 것(위력 최소값, 없으면 40), 피해 0.5배. 필살기는 위력 그대로 1.2배.
- **잡기(포켓몬 고 방식)**: 야생을 이기면(체력 0) 잡기 화면으로 바뀐다. 오디가 가운데 서 있고, 주위에 **줄어들었다 커지는 원**(초록=쉬움, 노랑, 빨강=어려움: 등급에 따라 색). 화면 아래 로프를 **위로 휙 쓸어 던진다**(키보드: 스페이스를 누른 채 떼기 = 힘). 원 안에 맞으면 원이 작을수록 보너스(Nice ×1.3, Great ×1.6, Excellent ×2), 빗나가면 로프만 잃는다. 맞으면 로프가 감싸고 3번 흔들림(기존 `ropeSequence`). 실패하면 오디가 튀어나오고 다시 던질 수 있다. 가끔(10%) 도망간다. 튼튼한 로프 선택 버튼.
- **트레이너전**: 상대 팀을 차례로(쓰러지면 다음 오디가 나온다는 문구). 잡기 없음.
