# 1단계 이후 남은 작업

1단계 최종 리뷰에서 나온 항목이다. 다음 단계 계획을 쓸 때 해당 시점의 항목을 작업으로 넣는다.

## 2단계 중

- 기술 풀 보강: 레벨 10에서 기술 1개인 종이 79, 레벨 50에서도 1개인 종이 8개 안팎이다. Red/Blue 기술머신 기술을 레벨 습득으로 추가한다.
- 위력 보정: 충전, 반동, 재충전 기술은 부가 효과가 없어 지나치게 강하다. 솔라빔(120), 파괴광선(150), 돌진류의 위력을 낮추고 연속 타격 기술은 평균 타수만큼 올린다.
- 꿈먹기는 잠든 상대에게만 통하게 하거나 뺀다.
- `build-data`에 재시도를 넣는다.
- 전기자석파가 땅 타입에 통하는 문제를 고친다.
- `Action`에 "행동 없음"을 추가한다. 포획 실패나 아이템 사용 뒤에도 상대가 공격해야 한다.
- 팀 전투 UI를 검증한다: 양쪽 동시 강제 교체 테스트, 내 포켓몬과 상대 구분 문구("가랏"은 내 쪽만), 상태 배지 즉시 갱신, 살아 있는데 HP 0%로 보이는 반올림.

## 3단계 전

- `isLegalAction`에 승패, 강제 교체 대기, 기절, 정수 인덱스 검사를 추가한다.
- `resolveForcedSwitch`의 입력을 검증한다. 턴 번호를 올리지 않으므로 중복 요청 방지는 별도로 설계한다.
- `rngState`는 참가자가 읽을 수 없는 서버 전용 칸에 둔다. 읽을 수 있으면 명중과 급소를 예측할 수 있다.
- 턴 상한이나 무승부 규칙을 넣는다. 서로 공격이 안 통하는 포켓몬이 마지막에 만나면 끝나지 않을 수 있다.
- 내 마지막 포켓몬이 상대를 쓰러뜨린 턴에 독으로 쓰러지면 승패가 동전 던지기가 된다. 승부가 난 뒤에는 턴 끝 데미지를 건너뛴다.
- 시드 고정 AI 대 AI 시뮬레이션을 회귀 테스트로 추가한다(JSON 왕복 포함).
- Deno에서 엔진과 데이터 로딩을 실제로 실행해 본다.

## 4단계 전

- AI 점수를 위력 근사 대신 실제 데미지 공식으로 바꾼다.
- 회복, 자속, 명중 분기 AI 테스트를 추가한다.
