# 오디 월드

「Catch an Oddie」의 오디들로 만든 2D 타일 모험 게임입니다(학교 활동). 폰과 컴퓨터 브라우저에서 돌아갑니다.

## 하는 법
- 오디 마을 연구소에서 박사님께 첫 오디를 받습니다.
- 풀숲을 걸으면 야생 오디가 나옵니다. 싸워서 이긴 뒤 로프를 휙 던져 잡습니다.
- 네 구역(초원·사막·설원·화산)의 체육관 관장을 이겨 배지 4개를 모으면 챔피언의 전당에 들어갈 수 있습니다.
- 센터에서 회복, 상점에서 로프·회복약을 삽니다.

## 조작
| | 폰 | 컴퓨터 |
|---|---|---|
| 걷기 | 왼쪽 아래 십자키 | 방향키 / WASD |
| 달리기(1.6배) | 십자키를 길게 누르기 | 걸으면서 X 또는 Shift |
| 말 걸기·다음 | 화면 탭 | Z, Enter, Space |
| 취소 | — | X, Esc |
| 메뉴 | 아래 가운데 둥근 버튼 (왼쪽 위 ▤ = 도감) | 둥근 버튼, 서서 X |
| 전투 | 탭 = 공격, 좌우로 쓸기 = 피하기, 필살기 버튼 | Space/Z = 공격, ←/→ = 피하기, 1·2 = 필살기 |

메뉴: 도감, 팀(오디를 누르고 「맨 앞으로」로 선두 바꾸기), 가방, 배지, 친구 대전, 계정, 처음부터.

## 실행
```bash
npm install
npm run dev      # http://localhost:5173/oddie-world/ (같은 와이파이 폰에서도 접속 가능)
npm test         # 테스트
npm run build    # dist/ 에 빌드
```
친구 대전과 계정 저장은 Supabase를 씁니다(공개 주소·키는 `src/online/supabaseConfig.ts`). 로그인하지 않으면 게스트로 이 기기에만 저장됩니다.

## 배포
`main`에 push하면 GitHub Actions(`.github/workflows/deploy.yml`)가 테스트·빌드 후 GitHub Pages에 올립니다.
