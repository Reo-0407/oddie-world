# 오디 월드

「Catch an Oddie」의 오디들로 만든 2D 타일 모험 게임입니다(학교 활동). 폰과 컴퓨터 브라우저에서 돌아갑니다.

## 하는 법
- 오디 마을 연구소에서 박사님께 첫 오디를 받습니다.
- 풀숲을 걸으면 야생 오디가 나옵니다. 싸워서 이긴 뒤 로프를 휙 던져 잡습니다.
- 네 구역(초원·사막·설원·화산)의 체육관 관장을 이겨 배지 4개를 모으면 챔피언의 전당에 들어갈 수 있습니다.
- 센터에서 회복, 상점에서 로프·회복약을 삽니다.
- **사탕과 강화**: 잡으면 그 종 사탕 3개(연속 잡기면 더), 같은 종을 박사에게 보내면 1개. 팀·박스에서 오디를 누르고 「강화」로 사탕과 코인을 써서 1레벨씩 올립니다(배지 0/1/2/3/4개 → 최대 Lv.15/22/28/34/50). 팀 메뉴의 「박스」 탭에서 박스 오디를 팀과 바꿀 수 있습니다.
- **매일 보상**: 하루 처음 들어오면 7일 달력이 뜹니다(코인 → 로프 → 튼튼한 로프 → 회복약 …, 7일째는 튼튼한 로프 5개 + 그날 반짝이 확률 ×3). 하루라도 거르면 1일째부터.
- **낚시**: 오디 마을 연못의 낚시꾼에게 낚싯대를 받고, 물을 바라보고 A(탭)로 던집니다. "!"가 뜨면 0.8초 안에 탭! 물 타입 오디와 싸웁니다(마을 연못, 숲·길의 물, 사막 오아시스, 설원 호수의 얼음 구멍).
- **챔피언 뒤**: 체육관 관장과 하루 한 번 재도전(레벨 +12, 큰 코인과 이상한 사탕 3개). 전당 앞마당에서는 매주 바뀌는 전설의 **레이드 보스**(체력 5배, 3분, 오디 3마리까지 자유 교체)에 도전하고, 이기면 황금 로프 5개로 잡아 봅니다.
- **퀘스트**: 오디 센터 게시판(잡기·이기기·Excellent·숨은 물건·트레이너·낚시·강화).

## 조작
| | 폰 | 컴퓨터 |
|---|---|---|
| 걷기 | 왼쪽 아래 십자키 | 방향키 / WASD |
| 달리기(1.6배) | 십자키를 길게 누르기 | 걸으면서 X 또는 Shift |
| 말 걸기·다음 | 화면 탭 | Z, Enter, Space |
| 취소 | — | X, Esc |
| 메뉴 | 아래 가운데 둥근 버튼 (왼쪽 위 ▤ = 도감) | 둥근 버튼, 서서 X |
| 전투 | 탭 = 공격, 좌우로 쓸기 = 피하기, 필살기 버튼 | Space/Z = 공격, ←/→ = 피하기, 1·2 = 필살기 |

메뉴: 도감(사탕 수), 팀(팀·박스 탭, 오디를 누르면 강화·맨 앞으로·박스로·박사에게 보내기), 가방, 퀘스트, 배지, 친구 대전, 계정, 처음부터.

## 실행
```bash
npm install
npm run dev      # http://localhost:5173/oddie-world/ (같은 와이파이 폰에서도 접속 가능)
npm test         # 테스트
npm run build    # dist/ 에 빌드
```
친구 대전과 계정 저장은 Supabase를 씁니다(공개 주소·키는 `src/online/supabaseConfig.ts`). 아이디와 숫자 4자리(PIN)로 가입·로그인하며, 저장은 계정(클라우드)과 이 기기에 함께 남습니다.

## 배포
`main`에 push하면 GitHub Actions(`.github/workflows/deploy.yml`)가 테스트·빌드 후 GitHub Pages에 올립니다.
